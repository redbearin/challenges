You're given an array containing numbers from 1 to n, but one number is missing.

Write a function that finds and returns the missing number.

function findMissingNumber(arr, n) {
  // Your code here
}

Examples:

findMissingNumber([1, 2, 4, 5], 5);
// 3

findMissingNumber([2, 3, 1, 5, 6], 6);
// 4

findMissingNumber([1, 3], 3);
// 2

findMissingNumber([2, 3, 4, 5], 5);
// 1

The array is not guaranteed to be sorted.

Bonus: Solve it in O(n) time without sorting the array.

Extra bonus: Can you solve it without creating another array?
