Write a function called countVowels that takes a string and returns the number of vowels (a, e, i, o, u) in that string.

countVowels("hello");       // 2
countVowels("JAVASCRIPT");  // 3
countVowels("rhythm");      // 0
countVowels("I love JS");   // 3

Requirements: It should handle uppercase and lowercase letters, and an empty string should return 0.
